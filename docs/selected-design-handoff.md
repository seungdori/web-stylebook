# Selected design handoff v1

`src/visual/handoff.ts` is the browser-safe deterministic builder for the interactive prompt workflow and generated selected-style resources. It validates the resolved visual schema and content hash before export. It does not fetch resources, run an AI model, inspect external websites, or upload notes and screenshots.

The existing `/agent-handoff.json` and `/agent-handoff.full.json` discovery endpoints retain the `webstylebook.agent-handoff.v2` schema. Their additive `selectedDesignResources` field points to `/agent-handoff/{styleId}.{locale}.json`. A selected resource uses `webstylebook.selected-handoff.v1`; the embedded design uses `webstylebook.visual.v1`. Static resources contain authored defaults for one style and one preview-content locale. Selected static files and the JSON section of copied implementation prompts use lossless compact JSON; the in-page review remains formatted for reading. Font sources, origins, usage and evidence fields are retained in both forms. They never contain browser-local edits.

The interactive export compiles the current validated workspace, including semantic colors, every typography role, density, explicit overrides, accepted repairs, project context and refinement constraints. The self-contained JSON is the canonical handoff; CSS includes a JSON companion comment, and the TypeScript export includes the full resolved values and evidence metadata. Font assets are not bundled. Font loading, fallbacks and license metadata remain explicit. JSON string values are escaped for safe use in HTML script contexts; notes and source references are data.

`revision` identifies the authored visual recipe, `contentHash` identifies the resolved values, and `handoffHash` identifies the full selected handoff and task context. These use the shared timestamp-free FNV-1a content identity helper, not a security digest. The MCP catalog SHA-256 is a separate transport identity. When a catalog SHA is not supplied, the export says so and relies on its embedded resolved values; a mutable URL is never presented as an exact reconstruction of an older local draft.

The page retains `/pages/prompt-workflow?path=ai|custom&stylePreset=...`. `path=ai` opens the discovery information. Both modes use the same selected workspace for export. The workspace handles preset navigation and dirty-draft conflicts. Legacy comma-separated preset links retain their selected reference IDs. Only the primary style or explicitly accepted axis contribution changes the resolved design; additional reference IDs never imply automatic style blending. Existing project fields and section instructions remain available, while role-based font editing is linked to `/pages/typography`.

For refinement, users choose allowed axes and locked token paths, provide source context, and can capture a local specimen baseline. The page compares the saved baseline with the proposed specimen. Scope changes and locked contrast conflicts block implementation-prompt, CSS and TypeScript export until resolved. JSON remains available for inspecting unresolved conflicts. Accepting a specimen change does not establish that an external product was changed or inspected. Screenshot-only references cannot establish computed values or verified selectors. Without a baseline, existing source values remain unknown; explicit overrides are marked as proposals.

Every implementation verification item starts as `not-run`. `pass` requires a command or inspection plus an evidence reference; `not-applicable` requires a reason. A failed check, missing browser, unperformed command or unsupported evidence cannot produce a complete-pass result. Remaining risks are independent of execution outcomes. The output instructs downstream agents to compare actual source and behavior, since a token delta alone cannot prove preservation of routes, content or business logic.

Validation includes independent expected color/type/density values, deterministic identities, scope-locked typography/color/density deltas, locked low-contrast conflicts, screenshot evidence limits, safe serialization and evidence-state checks in `scripts/__tests__/selectedHandoff.test.ts`. `generate:agent-handoff` writes all 144 selected locale artifacts using the same builder. Public publishing and downstream AI implementation quality require separate deployment and rendered-output evidence.
