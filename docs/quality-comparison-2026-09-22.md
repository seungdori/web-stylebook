# 2026-09-22 구현 검증 비교

공통 시각 명세를 실제 미리보기·편집·웹 내보내기·MCP에 연결하는 방향은 타당하다. 검증은 명세의 정확성, 실제 렌더링, 자원 사용량, AI 결과물의 품질로 나누었다. 아래 수치는 로컬 실행과 생성 산출물에 관한 결과이며, AI가 더 좋은 화면을 만든다는 주장은 아니다.

## 확인된 결과

- 자원 예산 **19개 통과**. 파일마다 gzip level 9를 적용한 크기와 선택 출력의 UTF-8 바이트를 검사했다.
- **48개 스타일, 지원하는 스타일·모드 55개 조합, EN/KO/JA와 수정 전후 330개 해석 사례**에서 웹 해석기·전달문·MCP의 전체 명세 및 JSON/CSS가 일치했다.
- 기본 모드의 **정적 전달문 144개**가 현재 웹 명세와 일치한다. 전체 카탈로그·다국어 사전·외부 참조 자료가 선택 출력에 들어오면 실패하도록 검사한다.
- **48 × 3 × 4 = 576개 MCP 호출**을 메모리 내 전송으로 측정했다. 외부 네트워크, 연결된 참조 리소스 조회, 모델 호출은 없다.
- 변경 전 웹 빌드와 기존 테스트 24개, MCP 빌드와 기존 테스트 207개를 분리된 고정 리비전에서 확인했다. 새 자원·변조 감지·AI 실행 기록 도구의 집중 테스트 10개도 통과했다.
- 로컬 프로덕션 미리보기의 **브라우저 검사 47개가 통과**했고 캡처 42개를 남겼다. 실제 선택 → 색상 → 타이포그래피 → 비교 축 적용 → 전달문 복사, 새로고침·언어 전환 보존, 세 언어·세 화면 폭의 편집 화면, 대표 스타일 여섯 개·두 화면 폭을 확인했다. 이것은 실행한 범위의 동작·렌더링 증거이며 모든 스타일 원본에 대한 주관적 완성도 판정은 아니다.

홈 초기 JS 증가는 실제 비용이다. 이를 성능 향상으로 표현하지 않는다. 전체 JS 증가율이 더 작은 이유에는 공통 코드가 앞에서 로드되도록 이동한 점이 포함된다. 정적 모듈 합계는 CSS, 글꼴, 이미지, 동적 기능 모듈과 실제 전송 헤더를 제외하며, 브라우저의 실제 전송량을 대신하지 않는다. 새 기능의 비용을 검토한 뒤 홈 250 KB, 편집 경로별 210 KB, 진입 스크립트 160 KB의 절대 예산을 적용했다.

선택 출력은 형식 공백과 반복되는 출처 표현을 줄이되 수정값·폰트 정보·출처·수리 제안은 유지했다. 텍스트만 읽는 MCP 클라이언트도 CSS와 현재 명세의 동반 자료를 받는다. JSON 응답의 초안 예산 72 KB는 최종 메타데이터를 포함한 72,488 B에 부족했으므로, 원인을 검토하고 76 KB로 명시했다. 예산을 자동으로 넓히거나 필드를 빼서 통과시키지 않았다.

## 증거와 재현

- [변경 전 측정](quality-baseline-2026-09-22.json): 웹 `c6d037cb630969eb726b8e73b3c3af7360a95c6f`, MCP `2aee594646c0060588f164989638bcde8d5830b6`에서 재현 가능하다.
- [적용 후 측정](quality-after-2026-09-22.json): 작업 디렉터리의 프로덕션 빌드·파일 해시·실행 환경·예산 결과를 기록한다. 아직 커밋하거나 게시한 릴리스라는 뜻은 아니다.
- [전체 명세 일치 검사](quality-parity-2026-09-22.json): visual library `sha256:c48a939689b40e643c54f320f52bb021c7c8713e8f163a086597d299b2d67a01` 기준이다.
- [재현 명령과 예산 정책](quality-regression.md), [예산 값](quality-budgets.json), [AI 비교 실행 절차](quality-ai-evaluation.md).

브라우저 검증 결과는 별도 `output/playwright/webstylebook-fidelity/browser-smoke/report.json`에 기록한다. 검사 47개, 실패 0개, 캡처 42개를 확인했으며, 실행 대상은 `http://127.0.0.1:4175`, 도구는 `agent-browser 0.38.1 / Chromium`이다. 캡처는 동일 폴더에 있고 CI에서는 `browser-smoke-<commit>` 산출물로 보관하도록 구성했다. 변경 전 캡처는 `output/playwright/webstylebook-fidelity/`의 `before-home-desktop.png`, `before-color-desktop.png`, `before-brutalist-color.png`, `before-color-mobile.png`에 있다.

위 자원 측정 파일의 `browserTransfer`, `browserInteraction`, `allocation`, `liveModelComparison`은 이 도구가 측정하지 않았다는 뜻으로 계속 `not-run`이다. 브라우저 작업 흐름이 통과해도, 측정하지 않은 콜드/웜 네트워크 전송량·상호작용 시간·장기 작업 시간·할당량까지 통과했다고 바꾸지 않는다. 변경 전 전역 글꼴 요청 관찰과 스크린샷은 보존하지만, 남기지 않은 구조화된 시간·전송 수치를 사후에 만들어 넣지 않았다.

AI 비교 도구는 여섯 제품 과제, 최소 세 번의 짝지은 반복, 고정 모델·시작 리비전·예산·입력 해시, 실패 결과 보존을 지원한다. 실제 모델 비교와 토크나이저 측정은 **실행하지 않았다**. 전체 스타일의 원본 화면에 대한 사람의 시각 검토나 장기 실사용 성능도 이 보고서의 통과 항목에 포함하지 않는다.
