## 실행 결과

- 웹: 타입 검사, ESLint, 다국어 검사, **123개 테스트**, 배포용 빌드, 카탈로그 생성 일치·검증 통과. 기존 애니메이션/원칙 예시 파일의 Fast Refresh 경고 4개는 남아 있으며 오류는 없다.
- MCP: 타입 검사, 빌드, **241개 테스트**, 공통 아티팩트·공유 소스 일치, 독립 설치한 npm 패키지의 오프라인 실행 통과.
- 명세 일치: **48개 스타일, 55개 원본 모드 조합, 330개 해석 사례, 144개 정적 전달물** 통과. 화면과 MCP의 역할·수정값·해시를 비교한다.
- 배포용 브라우저 자동 검사: **47개 통과**. 선택 → 색상 수정 → 글자 수정 → 비교 적용 → 복사, 실제 계산된 스타일과 JSON 일치, 새로고침, UI 언어와 콘텐츠 언어 분리를 확인했다. 영어·한국어·일본어 및 320·390·1440px에서 색상·글자·전달 도구를 검사하고 여섯 대표 스타일을 추가 확인했다.
- Home·Compare: 각각 세 언어와 세 화면 폭의 **9개 조합**을 별도로 검사했다. 기존 iframe 링크, 목적 필터, 빈 검색, 두 번 교환, 한 축 적용·취소·새로고침, 키보드 포커스를 확인했다.
- 저장소 오류·복구 브라우저 검사: **9개 통과**. 잘못된 저장값을 자동으로 덮어쓰지 않으며, 두 탭의 값을 명시적으로 선택할 수 있다.
- 글꼴 실패와 잘못된 입력: 외부 폰트 요청을 차단해 대체 상태를 확인했다. 색·숫자 입력 오류는 마지막 유효 값을 유지하고 복사를 막으며, 전체 되돌리기에서 임시 입력도 복구한다.
- JavaScript가 꺼진 경우를 위한 정적 설명과 스타일별 기본 JSON 링크가 생성된 한국어 HTML에 포함됨을 확인했다. 이것을 JavaScript 비활성 브라우저의 시각 검사로 기록하지 않는다.

브라우저 근거는 `output/playwright/webstylebook-fidelity/`의 `browser-smoke/report.json`, `compare-home-evidence.json`, `workspace-browser-report.json`과 PNG에 있다. 이 경로는 대용량 테스트 결과물로 Git에서 제외된다. 재실행: `npm run build && npm run quality:browser`.

## 남은 경계

초기 홈페이지 JavaScript가 약 **149 KB → 225 KB (gzip, 약 51% 증가)**했다. 공통 명세·검증 가능한 편집 상태와 실제 예시의 비용이다. 전역 폰트 전체 요청은 제거했으나 성능이 전반적으로 빨라졌다고 주장하지 않는다. 측정 기준과 검토한 예산은 품질 비교 문서에 있다.

모든 원본 페이지·모든 상태를 사람이 시각 검수한 것은 아니다. 반투명·그라데이션의 실제 대비, 글꼴별 모든 글리프, 장기 사용 성능과 플랫폼별 차이는 해당 화면에서 추가 확인할 항목이다. 예시의 일부 대비 실패는 그대로 표시하고, 사용자 승인 없이 색상을 바꾸지 않는다.

실제 AI 모델의 반복 생성 비교는 실행하지 않았다. 생성물의 미감이나 수정 횟수가 개선됐다는 수치는 제시하지 않는다. 검증은 로컬 구현과 배포용 산출물 기준이며 **커밋·푸시·서비스 배포·npm 게시를 수행하지 않았다**.

MCP 감사 결과 계약도 검증했다. 5개 명시적 화면·언어·폭의 206개 적용 슬롯을 기록했고 계약 검증은 유효하다. 증거로 뒷받침된 120개 PASS와 적용 제외 5개를 기록했으며, 별도 증거가 충분하지 않은 81개 항목은 `NOT_VERIFIED`로 보존했다. 이 숫자는 미감 점수나 전체 접근성 인증이 아니다. 특히 자동 동작 검사의 성공을 모든 시각·상태 검사의 성공으로 확대하지 않는다. 자세한 기록은 `output/playwright/webstylebook-fidelity/audit-result.json`에 있다.
